# /innovate — ScrapProsp (2026-06-05)

## Idees generees

### [PRIO 1] Radar de nouveaux prospects
> Cron hebdo qui scrape automatiquement Google Maps sur les zones/metiers configures et detecte les nouvelles fiches (pas encore en base). Notification push quand un nouveau prospect sans site web apparait. Premier arrive = premier contacte.
> Stack : Cron VPS + comparaison base existante + webhook Telegram/Discord pour notif.
> Effort : 2-3 jours

### Sequence auto multi-touch (Nurturing)
> Au lieu d'un SMS unique, programmer une sequence : J+0 SMS, J+3 relance DM Instagram, J+7 rappel avec screenshot de leurs avis Google negatifs. Chaque etape s'annule si le prospect repond.
> Stack : Cron VPS existant + table sequences + etat machine simple.
> Effort : 1-2 jours

### Page "Votre score Google" publique (Viralite)
> Chaque prospect recoit un lien /score/{id} qui montre son rating Google, sa position vs concurrents, ses avis recents, et un "score de visibilite". Le prospect peut partager cette page. En bas : "Vous aussi, testez votre score". Chaque partage = acquisition gratuite.
> Stack : Donnees existantes (competitor_reports, scraper). Page Next.js publique.
> Effort : 1-2 jours

### Reponse vocale aux avis Google (IA)
> Proposer au prospect : "on a vu que tu as 3 avis sans reponse — voici les reponses qu'on te suggere". Genere par Claude Haiku. Bouton "Copier la reponse". Service gratuit qui cree la confiance.
> Stack : API Google Places pour les avis + Claude Haiku. Integree dans /score.
> Effort : 3-4 jours

### Carrousel Instagram auto-genere (Social proof)
> Pour chaque prospect contacte, generer un carrousel Instagram de 3-5 slides : "Votre salon vu par Google" -> screenshot des avis -> maquette du site -> CTA.
> Stack : Template HTML -> screenshot Playwright (VPS) -> images pretes.
> Effort : 1 semaine

### Dashboard de scoring commercial (Gamification)
> Transformer le CRM en jeu : streak de jours consecutifs, badges, classement, objectif quotidien avec barre de progression.
> Stack : Cote client, table daily_stats ou calcul a la volee.
> Effort : 2 jours

### Widget "avis en temps reel" comme teaser (Conversion)
> Widget iframe que le prospect colle sur sa page Facebook/Instagram : affiche ses avis Google en temps reel. Gratuit, sans engagement. Chaque affichage = pixel qui track l'audience.
> Stack : API avis Google + iframe public + compteur Supabase.
> Effort : 1 semaine

### Le prospect construit son propre site (Inversion)
> Envoyer un lien vers un editeur ultra-simplifie (3 champs : nom, photo, couleur) qui genere le site en live. Le prospect joue, se projette, clique "Publier" = lead qualifie chaud.
> Stack : Builder no-code minimaliste avec templates existants.
> Effort : 2+ semaines
