# Suivi des SMS — Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax. No test runner in this repo → verification = `npx tsc --noEmit` + `npm run build` + runtime check.

**Goal:** Ajouter une section `/sms` qui liste tous les SMS envoyés/reçus avec leur réponse classée positive/négative, alimentée par une table `sms_messages` (envoi + webhook + backfill Twilio) et un classement IA Haiku.

**Architecture:** Table Supabase `sms_messages` = source de vérité. Loggée à l'envoi (`/api/blast`, `/api/sms`), au webhook entrant, et par backfill Twilio. Classement IA lazy via `/api/sms/classify`. UI page client calquée sur `/carte`.

**Tech Stack:** Next.js 15 App Router, Supabase JS (clé publishable), Twilio SDK, `@anthropic-ai/sdk` (Haiku 4.5), Tailwind v4, lucide-react.
