## Construit dans la foulée (validé par Nicolas)

### ✅ Tracking démo + notif Telegram temps réel
Table `demo_views` (migration 009) + beacon/heartbeat sur les démos publiques
(`DemoLive`) + `/api/demo/track`. Notif Telegram « 👀 X regarde sa démo — visite n°N »
(cooldown 30 min anti-spam). Config : `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`.

### ✅ Countdown d'expiration (FOMO)
Le chrono de 7 jours démarre à la PREMIÈRE ouverture de la démo
(`demo_first_viewed_at` -> `demo_expires_at`). Bandeau compte à rebours flottant
(rouge < 24 h), écran « Démo expirée » (flou + CTA téléphone NMF) après échéance.

### ✅ Démo télécommandée en live (Supabase Realtime)
Pendant l'appel, panneau « Démo live » dans la CallModal (`LiveRemote`) :
changer le template, scroller vers une section, envoyer un ✨ — sous les yeux
du prospect, en temps réel (broadcast channel `demo-{id}`, reçu par `DemoLive`).
La presence indique « 🟢 Il regarde ! » quand le prospect est sur la démo.

### ✅ Bouton « Je le veux » + Stripe (paiement en TOTALITÉ, pas d'acompte)
CTA flottant sur la démo -> Stripe Payment Link avec `client_reference_id`.
Clic tracké + notif Telegram. Webhook `/api/stripe/webhook`
(`checkout.session.completed`) -> prospect `positive` + `paid_at` + notif 💰.
Config : `STRIPE_PAYMENT_LINK` + `STRIPE_WEBHOOK_SECRET`.
