# Product

## Register

product

## Users

Nicolas (NMF Agence), seul utilisateur. Contexte : session quotidienne de prospection Instagram (envoi de DM selon une file scorée, suivi des relances, rapport concurrentiel Google Maps/Ads par prospect). Desktop, sessions courtes et répétées — l'outil doit être lisible d'un coup d'œil et rapide à manipuler.

## Product Purpose

Cockpit interne de prospection : scraper des prospects locaux (artisans, beauté haut ticket), les scorer, dérouler les trames DM (M1-M9), suivre le pipeline (todo → contacté → positif/négatif) et les quotas de chauffe du compte. Succès = file d'envoi du jour traitée vite et sans erreur (bonne trame, bon message, bon prospect).

## Brand Personality

Sobre, efficace, pro. Trois mots : clair, calme, précis. L'outil doit s'effacer derrière la tâche — pas de démonstration visuelle.

## Anti-references

- Dashboard « dark cockpit gamer » : néons, glows, gradients partout (direction explicitement écartée par Nicolas).
- Glassmorphisme décoratif généralisé.
- Densité illisible : badges multicolores empilés sans hiérarchie.

## Design Principles

1. **La file d'abord** : ce qu'il faut envoyer aujourd'hui est l'information n°1 de la page.
2. **Un accent, des états** : le violet NMF sert aux actions et sélections, jamais à décorer ; les couleurs restantes signalent des états (hot/warm/cold, positif/négatif).
3. **Lisible d'un coup d'œil** : hiérarchie typographique nette, air généreux, familiarité Notion/Stripe.
4. **Ne jamais casser le workflow** : chaque refonte préserve les actions existantes (copie de messages, marquage, filtres).

## Accessibility & Inclusion

Outil interne mono-utilisateur : viser AA (contraste ≥ 4.5:1 texte courant), reduced-motion respecté, pas d'exigence WCAG formelle au-delà.
